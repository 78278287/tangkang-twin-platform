本文件夹为“糖康孪生平台”网页端源代码，存放系统前后端程序、静态资源、模型文件与配置文件，是网页功能的核心实现载体。
.idea/：IDE项目配置文件夹
assets/：系统通用静态资源文件夹
images/：网页图片资源文件夹
病例分析（代码）/：病例分析相关后端代码
数据库/：数据库相关配置与脚本
123.py、app.py：Python后端服务与业务逻辑脚本
*.html：登录、首页、科普、论坛等各功能页面文件
diabetes_model.pkl、scaler.pkl：糖尿病预测与数据标准化模型文件
server.js、build.js：前端服务启动与构建脚本
requirements.txt：Python项目依赖列表
.env：环境变量配置文件
*.csv：糖尿病相关数据集文件
糖尿病预测系统.spec：可执行程序打包配置文件
